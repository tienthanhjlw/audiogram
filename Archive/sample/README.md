Sample assets
-------------

This folder contains a small example SRT file you can use to test subtitle burn-in.

Bring your own audio and background image when testing:
- Audio: mp3, wav, m4a, flac, aac
- Background: png or jpg

Steps:
1) Launch the app (npm run tauri dev)
2) Select an audio file
3) Select a background image
4) Optionally select sample/example.srt
5) Choose resolution, FPS, wave color/mode
6) Click "Render MP4" and pick an output path
